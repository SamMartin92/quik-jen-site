# Quik-Jen Site

## Instructions for Viewing a Preview

To view a preview of the webpage, follow the steps below:

1. Open your terminal or command prompt.
2. Navigate to the project directory where you have cloned the repository.
3. Run the following command to start the local server:
   
   ```bash
   npm start
   ```

4. Open your web browser and go to `http://localhost:3000` to see the preview of the webpage.

Enjoy exploring!
